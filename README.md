# 🧩 TileForge Studio — Motor de Ampliación en Mosaico & Posterización

Aplicación web Open Source para dividir, reescalar e imprimir imágenes (`PNG`, `JPG`, `SVG`) y documentos `PDF` a través de múltiples hojas físicas (Carta, A4, Oficio, Tabloide) con pestañas de pegado milimétricas y sin pérdida de calidad.

## ✨ Características Principales
- **Soporte Nativo de Imágenes y PDFs:** Rasterización vectorial de alta resolución mediante `PDF.js`.
- **Geometría Exacta de Impresión:** Cálculo en tiempo real de márgenes de impresora, pestañas de traslape (*overlap*) y marcas de corte.
- **Semáforo de Nitidez (DPI) y Filtros:** Modos Suavizado Bicúbico, Pixel Art (*Nearest Neighbor*) y Póster Semitono (*Halftone*).
- **Impresión Selectiva Anti-Atascos:** Activa o desactiva hojas individuales haciendo clic directamente en el lienzo interactivo.
- **100% Client-Side:** Procesamiento local en el navegador con `HTML5 Canvas` y `jsPDF`.
